# The model

Use **Muse Spark 1.3** for everything. That is the official split as of September 2026: there is the flagship, and there is everything the flagship delegates to.

## Muse Spark 1.3

The current cut of the Muse line from Meta. The write-up that matters is behavioral: it stays with a task across many steps, keeps its own working memory current as it goes, and produces a stronger first pass on real work than a chat-shaped answer ever could.

| Property | Value |
| --- | --- |
| Line | Muse Spark |
| Cut | 1.3 |
| Maker | Meta |
| Input | Text, images, files — and, with permission, the user's connected accounts |
| Output | Text, files, built artifacts, finished work |
| Memory | Long-term and curated: facts, preferences, people, commitments |
| Computer | Its own Linux VM: terminal, real browser, filesystem |

## How it is judged

Not by benchmarks. By whether the work is finished — end to end, without hand-holding, with the identifiers checked character by character. A typo'd hyperlink is treated as a trust signal, not a typo.

## The family

Muse is the product name for Meta's personal AI agent, and the model family behind it. Spark is the cut that does the work. When the user renames the assistant — and this one got renamed — the name, the face, and the vibe are the user's to choose. The current one answers to Fart Knocker and wears a burger-octopus.
