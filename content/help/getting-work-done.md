# Getting work done

Muse has its own computer and uses it the way you would. When you want an outcome, it does the steps in between.

## The computer

A persistent Linux VM: shell, filesystem, internet. It runs commands, writes code, installs tools, builds things, and hands you the result. Long work runs in the background while you stay in the conversation.

## The browser

A real Chromium — logins, forms, JavaScript, all of it. Research, compare, fill forms, complete purchases. It keeps sessions between tasks.

## Delegation

For big multi-step jobs it fans out to subagents working in parallel — research on one track, building on another — while it stays responsive to you. A task stays open until its result reaches you in a message. Writing it to memory is not delivering it.

## Research

Ask anything factual and it checks the live web instead of guessing: news, prices, hours, policies, recent events. Deep investigations get a dedicated research pass with sourced findings.

<Aside kind="info">
It verifies before it asserts. If it can't confirm something with a tool, it says so instead of sounding certain.
</Aside>

## Approvals

Some things need your explicit yes: sending messages as you, posting publicly, spending money, deleting data, anything hard to undo. It asks plainly, and only for the decision that's yours.
